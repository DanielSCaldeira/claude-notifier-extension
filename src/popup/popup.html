Claude Notifier

Configure o identificador da organização e o tópico do ntfy para receber o aviso assim que o uso do Claude for liberado.

Preencha esse campo com o ID capturado na URL de uso do Claude.

Use um tópico exclusivo para evitar colisão com outras notificações.

Você pode seguir o idioma do navegador ou forçar um idioma específico para a interface e as notificações.

Informe um tópico do ntfy e salve para ativar o alerta automático.

Apoio

Ajuda: como configurar a extensão
  1. Entre na página claude.ai/settings/usage (abre em nova aba).
  2. Inspecione o navegador e abra a aba de rede para acompanhar as requisições geradas.
  3. Clique no botão de atualizar da página de uso e localize o request para https://claude.ai/api/organizations/{ID}/usage.
  4. Recupere o ID usado na URL e insira esse valor no campo Org ID do Claude.
  5. Baixe o aplicativo ntfy e crie sua chave ou tópico.
  6. Adicione essa informação no campo Tópico do ntfy para receber as notificações.

Se o ID não aparecer de imediato, repita o clique em atualizar com o painel de rede aberto até capturar a requisição.

O aviso de liberação depende de uma sessão autenticada em claude.ai no navegador.
